**Last Dawn — Hold the Kingdom** is a 3D survival/defense game built for make.fun's *Make the best game* bounty. You hold a small kingdom through day/night cycles: gather wood, fiber, stone and iron by hand or with tools, craft planks and defenses at the forge, raise walls, shrine and knight, and survive escalating night waves of runners, brutes, wisps and crawlers that each break your line differently.

Built with Three.js r128, fully vendored — no CDN, no network, no external assets. All textures, models and sound are generated procedurally at runtime from code. Plays in a desktop browser and on a phone (touch controls plus on-screen buttons).

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
